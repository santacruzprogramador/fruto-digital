# Fruto Digital

Sitio web de **Fruto Digital**, desarrollado para ofrecer servicios de diseño y desarrollo web profesional para negocios, empresas, profesionales y emprendedores.

El proyecto está orientado a crear sitios web **responsive, optimizados para buscadores y enfocados en una buena experiencia de usuario**.

## 🚀 Tecnologías

* HTML5
* CSS3
* JavaScript
* SEO técnico y On-Site
* Diseño responsive

## 🌐 Sitio web

👉 https://frutodigital.com

## 📂 Estructura

```text
├── assets/                       # Favicons, fuentes, iconos e imágenes
├── blog/
│   ├── articulos/                # Artículos del blog
│   ├── categorias/
│   ├── css/                      # Estilos del blog y artículos
│   ├── imagen/
│   ├── js/
│   └── index.html                # Índice del blog
├── components/
│   ├── footer/                   # Pie compartido
│   └── nav/                      # Navegación compartida
├── css/
│   └── styles.css                # Estilos globales
├── faq/
│   └── index.html                # Preguntas frecuentes
├── js/
│   └── main.js
├── servicios/
│   ├── auditoria-seo/
│   ├── landing-page/
│   ├── catalogo-digital/
│   └── web-corporativa/
├── index.html                    # Página principal
├── llms.txt
├── robots.txt
├── sitemap.xml
└── README.md
```

El sitio está organizado como páginas HTML estáticas con estilos CSS y JavaScript. La navegación y el pie se cargan desde componentes compartidos.

## 🔎 SEO

El proyecto incorpora diferentes elementos orientados al SEO técnico y On-Site, entre ellos:

* Etiquetas `title` y `meta description`
* Estructura semántica HTML5
* Encabezados jerárquicos
* URLs amigables
* Sitemap XML
* Robots.txt
* Datos estructurados mediante Schema.org
* Etiquetas Open Graph
* Imágenes optimizadas
* Diseño responsive
* Configuración para indexación en buscadores
