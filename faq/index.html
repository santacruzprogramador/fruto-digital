Preguntas frecuentes sobre diseño web

Diseño de landing pages

¿Puedo usar una landing page para una campaña publicitaria?

+

Sí. Puede presentar una oferta o servicio y ayudar a recibir consultas desde una campaña. El resultado también depende de la propuesta, el público y la configuración. Conocé las landing pages.

¿Cuántas secciones incluye la landing page?

+

El plan contempla hasta cuatro secciones: Inicio, Acerca, Servicios y Contacto. Si necesitás una estructura distinta, la definimos según el alcance del proyecto. Ver el servicio de landing page.

¿La landing page incluye formulario y contacto por WhatsApp?

+

Sí. El plan incluye un formulario de contacto y un botón directo a WhatsApp para que tus potenciales clientes puedan consultarte. Conocé qué incluye.

Diseño web corporativo

¿Qué diferencia hay entre una landing page y una web corporativa?

+

Una landing page se concentra en una oferta y una acción, como recibir consultas o presentar una campaña. Una web corporativa organiza la información de tu empresa, sus servicios y formas de contacto en distintas secciones.

¿Cuántas secciones o páginas puede tener una web corporativa?

+

El plan contempla hasta seis secciones o páginas independientes. La estructura se organiza según la información y los servicios que quieras presentar. Ver el servicio de web corporativa.

¿Puedo presentar varios servicios de mi empresa en una web corporativa?

+

Sí. La estructura puede organizar la información de tu empresa, sus servicios y las formas de contacto en distintas secciones o páginas, dentro del alcance acordado. Conocé el servicio.

Catálogo digital

¿Qué es un catálogo digital?

+

Es una página para mostrar tus productos, sus fotos y detalles. Cada producto puede tener un botón para consultarte por WhatsApp; vos coordinás el pedido directamente. Los pagos y la entrega se acuerdan directamente entre vos y el cliente. No incluye carrito ni pagos en línea. Conocé el catálogo digital.

¿Cómo consulta un cliente por un producto?

+

Puede explorar el catálogo y usar el botón de contacto de un producto para escribirte por WhatsApp. Vos coordinás la consulta o el pedido directamente con el cliente.

¿Puedo actualizar los productos del catálogo?

+

Sí. El plan contempla un panel de administración para actualizar los productos. Conocé el servicio de catálogo digital.

Diseño adaptable y desarrollo web

¿Los sitios se ven bien en celulares?

+

Sí. Diseñamos las páginas para que el contenido y la navegación se adapten a celulares, tablets y computadoras.

¿Trabajan con WordPress o Wix?

+

No. Desarrollamos a medida con HTML, CSS y JavaScript para adaptar la estructura y las funciones a las necesidades del proyecto.

Presupuesto y pagos

¿Los precios publicados son definitivos?

+

Los precios publicados sirven como referencia inicial. El importe final puede variar según el alcance, las funciones y el contenido del proyecto. Revisamos esos detalles y confirmamos el presupuesto antes de comenzar. Consultanos por el presupuesto.

¿Cómo se define el presupuesto final?

+

Primero entendemos qué necesitás: tipo de sitio, secciones y funciones. Con ese alcance acordamos el precio y el plazo estimado antes de iniciar el trabajo.

¿Qué formas de pago aceptan?

+

Para los proyectos web, se abona un 50% para iniciar y el 50% restante después de revisar el sitio y antes de publicarlo. Aceptamos transferencia bancaria y Mercado Pago. Las opciones de pago se confirman al definir el alcance y el presupuesto del proyecto.

Proceso y plazos

¿Cuánto tarda en estar lista una página?

+

Como referencia, una landing page suele llevar entre 7 y 10 días; una web corporativa, entre 1 y 2 semanas; y un catálogo digital, según la cantidad de productos y el contenido. El plazo final depende del alcance, los materiales y las funciones que acordemos.

¿Qué necesito para empezar?

+

Para orientarnos, contanos qué hace tu negocio, qué querés lograr con la web y qué servicio te interesa. Si ya tenés textos, imágenes o referencias, podés compartirlos; definimos juntos lo que falte y el alcance antes de iniciar.

¿Puedo revisar el sitio antes de que se publique?

+

Sí. Revisás el sitio antes de publicarlo. En esa instancia se valida el resultado y se completa el pago acordado para avanzar con la publicación.

¿Ofrecen mantenimiento después de entregar la web?

+

Sí, ofrecemos planes de mantenimiento mensual. Las tareas incluidas se definen según el plan y las necesidades de tu sitio.

¿Cómo solicito un presupuesto?

+

Podés escribirnos por WhatsApp para conversar sobre el alcance y los próximos pasos.

Auditoría SEO y resultados

¿La auditoría SEO tiene costo?

+

La auditoría SEO inicial se ofrece gratis. Revisamos aspectos técnicos y de contenido para detectar oportunidades y sugerir qué conviene mejorar primero. Solicitá una auditoría SEO.

¿La auditoría SEO garantiza aparecer primero en Google?

+

No. Una auditoría ayuda a encontrar problemas y oportunidades, pero nadie puede garantizar una posición específica en Google. Los resultados dependen de muchos factores y requieren implementar mejoras y darles seguimiento.

¿Una web nueva va a aparecer enseguida en Google?

+

La estructura y el contenido pueden prepararse para facilitar que los buscadores comprendan el sitio, pero la indexación y las posiciones no son inmediatas ni se pueden garantizar. También influyen la competencia y la estrategia de contenidos.

¿Pueden revisar una web que ya tengo?

+

Sí. Podemos revisar el sitio mediante una auditoría SEO inicial y señalar aspectos técnicos y de contenido que convenga priorizar.

¿Cuánto tarda una auditoría SEO?

+

El plazo depende del tamaño y la complejidad del sitio. Te confirmamos una estimación al revisar la web. Conocé la auditoría SEO.

¿Qué revisan en la auditoría SEO?

+

Revisamos aspectos técnicos y de contenido que pueden dificultar que las personas encuentren o usen tu sitio, y sugerimos qué mejoras priorizar. Solicitá una auditoría SEO.

¿Qué recibo al finalizar la auditoría SEO?

+

Recibís una revisión de aspectos técnicos y de contenido, con oportunidades detectadas y sugerencias sobre qué conviene mejorar primero. Más información sobre la auditoría SEO.

¿La auditoría SEO incluye hacer los cambios en mi sitio?

+

La auditoría identifica y prioriza mejoras. Si después querés implementarlas, definimos el alcance de ese trabajo por separado, según lo que necesite tu sitio.
