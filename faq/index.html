Preguntas frecuentes sobre diseño web

Diseño de landing pages

¿Puedo usar una landing page para una campaña publicitaria?

+

Sí. Podés usarla para mostrar una oferta y recibir consultas desde una campaña. Los resultados también dependen de la oferta, el público y cómo esté armada la campaña. Conocé las landing pages.

¿Cuántas secciones incluye la landing page?

+

El plan incluye hasta cuatro secciones: Inicio, Acerca, Servicios y Contacto. Si necesitás otras, las definimos antes de empezar. Ver el servicio de landing page.

¿La landing page incluye formulario y contacto por WhatsApp?

+

Sí. El plan incluye un formulario y un botón de WhatsApp para que tus posibles clientes puedan consultarte. Conocé qué incluye.

Diseño web corporativo

¿Qué diferencia hay entre una landing page y una web corporativa?

+

Una landing page presenta una oferta y busca una acción, como recibir consultas. Una web corporativa muestra tu empresa, sus servicios y los datos de contacto en varias secciones.

¿Cuántas secciones o páginas puede tener una web corporativa?

+

El plan incluye hasta seis secciones o páginas. Las organizamos según la información y los servicios que quieras mostrar. Ver el servicio de web corporativa.

¿Puedo presentar varios servicios de mi empresa en una web corporativa?

+

Sí. Podés mostrar tu empresa, sus servicios y los datos de contacto en varias secciones o páginas, según lo acordado. Conocé el servicio.

Catálogo digital

¿Qué es un catálogo digital?

+

Es una página para mostrar tus productos, fotos y datos. Cada producto puede tener un botón para escribirte por WhatsApp. Vos y el cliente coordinan el pedido, el pago y la entrega. No incluye carrito ni pagos en línea. Conocé el catálogo digital.

¿Cómo consulta un cliente por un producto?

+

Puede buscar un producto y tocar el botón de WhatsApp para escribirte. Después coordinás la consulta o el pedido con el cliente.

¿Puedo actualizar los productos del catálogo?

+

Sí. El plan contempla un panel de administración para actualizar los productos. Conocé el servicio de catálogo digital.

Diseño adaptable y desarrollo web

¿Los sitios se ven bien en celulares?

+

Sí. Diseñamos las páginas para que el contenido y la navegación se adapten a celulares, tablets y computadoras.

¿Trabajan con WordPress o Wix?

+

No. Desarrollamos a medida con HTML, CSS y JavaScript para adaptar la estructura y las funciones a las necesidades del proyecto.

Presupuesto y pagos

¿Los precios publicados son definitivos?

+

Los precios publicados son una referencia. El precio final depende de lo que necesites, las funciones y el contenido. Revisamos esos detalles y confirmamos el presupuesto antes de empezar. Consultanos por el presupuesto.

¿Cómo se define el presupuesto final?

+

Primero definimos qué tipo de sitio necesitás y qué secciones y funciones tendrá. Antes de empezar, acordamos el precio y el plazo.

¿Qué formas de pago aceptan?

+

Para empezar un proyecto web, pagás el 50%. Pagás el resto después de revisar el sitio y antes de publicarlo. Aceptamos transferencia bancaria y Mercado Pago. Confirmamos las opciones al acordar el trabajo y el presupuesto.

Proceso y plazos

¿Cuánto tarda en estar lista una página?

+

Como referencia, una landing page suele llevar entre 7 y 10 días y una web corporativa, entre 1 y 2 semanas. El plazo del catálogo depende de los productos y el contenido. También influyen el trabajo y las funciones que acordemos.

¿Qué necesito para empezar?

+

Contanos qué hace tu negocio, qué querés lograr y qué servicio te interesa. Si ya tenés textos, imágenes o ejemplos, compartilos. Juntos definimos lo que falta antes de empezar.

¿Puedo revisar el sitio antes de que se publique?

+

Sí. Revisás el sitio antes de publicarlo. Cuando lo apruebes, completás el pago acordado y avanzamos con la publicación.

¿Ofrecen mantenimiento después de entregar la web?

+

Sí, ofrecemos planes de mantenimiento mensual. Cada plan indica qué tareas incluye para tu sitio.

¿Cómo solicito un presupuesto?

+

Podés escribirnos por WhatsApp para contarnos qué necesitás y definir los próximos pasos.

Auditoría SEO y resultados

¿La auditoría SEO tiene costo?

+

La primera auditoría SEO es gratis. Revisamos la parte técnica y los textos de tu web para encontrar qué conviene mejorar primero. Solicitá una auditoría SEO.

¿La auditoría SEO garantiza aparecer primero en Google?

+

No. La auditoría ayuda a encontrar problemas y mejoras posibles, pero nadie puede asegurar una posición en Google. Los resultados dependen de muchos factores y llevan tiempo.

¿Una web nueva va a aparecer enseguida en Google?

+

No necesariamente. Preparamos la web para que Google pueda leerla, pero aparecer en sus resultados puede llevar tiempo y no se puede garantizar. También influyen la competencia y el contenido del sitio.

¿Pueden revisar una web que ya tengo?

+

Sí. En la auditoría SEO inicial revisamos la parte técnica y los textos de tu sitio, y te indicamos qué conviene mejorar primero.

¿Cuánto tarda una auditoría SEO?

+

Depende del tamaño y de las funciones del sitio. Te damos una fecha estimada después de revisar la web. Conocé la auditoría SEO.

¿Qué revisan en la auditoría SEO?

+

Revisamos qué puede impedir que las personas encuentren o usen tu sitio. Después te contamos qué conviene mejorar primero. Solicitá una auditoría SEO.

¿Qué recibo al finalizar la auditoría SEO?

+

Recibís una revisión de la parte técnica y los textos de tu web. También te contamos qué encontramos y qué conviene mejorar primero. Más información sobre la auditoría SEO.

¿La auditoría SEO incluye hacer los cambios en mi sitio?

+

La auditoría encuentra y ordena las mejoras necesarias. Si después querés que hagamos esos cambios, acordamos por separado el trabajo que requiere tu sitio.
